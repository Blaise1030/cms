# SEO

Apply search-engine optimization when writing or reviewing site content:

- Give every page a single, descriptive `<h1>` and a logical heading hierarchy.
- Write a unique, descriptive title and meta description for each page.
- Add descriptive alt text to images.
- Use short, readable, descriptive URLs.
- Link between related pages where it helps users and search engines.
