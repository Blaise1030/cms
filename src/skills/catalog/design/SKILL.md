# Design

Follow the project's visual and interaction direction when building or changing UI.

This complements `DESIGN.md` and does not replace it. Read `DESIGN.md` for the project's
design tokens and decisions, and apply this skill's guidance on top of them:

- Keep layout, spacing, and typography consistent with the existing interface.
- Reuse existing components and patterns before introducing new ones.
- Make every state — loading, empty, error — look intentional.
