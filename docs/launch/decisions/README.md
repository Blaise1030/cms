# Decisions

One file per decision: `NNN-short-question.md`. Written by an agent, answered by the user in the
Monday or Thursday batch.

Nothing waits on an answer unless the file says so. If an agent is blocked, it still works on the
next unblocked item and says which file is holding it up.

---

## Template

```md
# NNN — <the question, as a sentence>

- **Asked by:** Marketer | Product Engineer
- **Opened:** YYYY-MM-DD
- **Answer needed by:** YYYY-MM-DD
- **Blocks:** <brief or issue>

## Recommendation

What I would do, and why, in two sentences.

## Alternatives

1. <option> — cost, risk
2. <option> — cost, risk

## If nobody answers

What I will do by default on the date above.
```
